# Lab Environment

In this lab environment, you will have GUI access to a Kali machine with access to a captured network packet file **test.pcap**.

**Objective:** Use network analysis techniques to identify and capture the following flags related to the infection and attack:

- **Flag 1:** What is the domain name (abcd.site) accessed by the infected user that returned a 200 OK response code?
- **Flag 2:** What is the IP address, MAC address of the infected Windows client?
- **Flag 3:** Which Wireshark filter can you use to determine the victim’s hostname from NetBIOS Name Service traffic, and what is the detected hostname for this malware infection?
- **Flag 4:** Which user got infected and ran the `mystery_file.ps1` PowerShell script?
- **Flag 5:** What User-Agent string indicates the traffic generated by a PowerShell script?
- **Flag 6:** Which wallet extension ID is associated with the Coinbase wallet?

# Tools

The best tools for this lab are:

- Wireshark

---
# Task 1

**Clue:** What is the domain name (abcd.site) accessed by the infected user that returned a 200 OK response code?

Open the provided `pcap` file in **Wireshark**, and set the filter to `http.response.code == 200` to see packets that match the description of the clue. The flag is located in the `Hypertext Transfer Protocol` section of the packet.

![](/assets/writeup_assets/network_based_attacks_ctf_1_writeup/flag1.png)
*Figure 1: Flag 1*

The flag is `623start.site`.

---
# Task 2

**Clue:** What is the IP address, MAC address of the infected Windows client?

In the same packet, this flag can be found in the `Ethernet II` section.

![](/assets/writeup_assets/network_based_attacks_ctf_1_writeup/flag2.png)
*Figure 2: Flag 2*

Flag 2 is `10.7.10.47, 80:86:5b:ab:1e:c4`.

---
# Task 3

**Clue:** Which Wireshark filter can you use to determine the victim’s hostname from NetBIOS Name Service traffic, and what is the detected hostname for this malware infection?

Use `nbns` to filter for `NetBIOS Name Service` traffic. Look under `NetBIOS Name Service` to find the hostname.

![](/assets/writeup_assets/network_based_attacks_ctf_1_writeup/flag3.png)
*Figure 3: Flag 3*

The flag is `nbns, DESKTOP-9PEA63H`.

---
# Task 4

**Clue:** Which user got infected and ran the `mystery_file.ps1` PowerShell script?

Search for packets containing the file name with `frame contains "mystery_file.ps1"`. Then, click on the packet data and copy as printable text.

![](/assets/writeup_assets/network_based_attacks_ctf_1_writeup/file_data.png)
*Figure 4: Copying the packet data*

Paste the text in a notepad and search for the file name. The flag will be found within the path containing the file name.

The path is `C:\Users\rwalters\Documents\mystery_file.ps1`, so the flag is `rwalters`.

---
# Task 5

**Clue:** What User-Agent string indicates the traffic generated by a PowerShell script?

Filter for `HTTP` packets that have a `User-Agent` field with `http.user_agent`. Click one of the packets and navigate to the `Hypertext Transfer Protocol` section. The `User-Agent` will appear.

![](/assets/writeup_assets/network_based_attacks_ctf_1_writeup/flag5.png)
*Figure 5: Flag 5*

The `User-Agent` field contains `Mozilla/5.0 (Windows NT; Windows NT 10.0; en-US) WindowsPowerShell/5.1.19041.3031`. The flag is `WindowsPowerShell`.

---
# Task 6

**Clue:** Which wallet extension ID is associated with the Coinbase wallet?

Similar to task 2, do `frame contains "Coinbase"`, copy the packet as printable text, paste it into a text editor, and search for `Coinbase` in the text. The flag will appear next to `Coinbase`.

![](/assets/writeup_assets/network_based_attacks_ctf_1_writeup/file_data_2.png)
*Figure 2: Copying the packet data*

The text found is `hnfanknocfeofbddgcijnmhnfnkdnaad|Coinbase`. The final flag is `hnfanknocfeofbddgcijnmhnfnkdnaad`.
